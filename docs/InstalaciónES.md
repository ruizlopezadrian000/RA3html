## Tipos de editores
Editores más conocidos:

**-Visual Studio Code (VS Code)** es un editor de código abierto gratuito desarrollado por Microsoft. Es compatible con una amplia gama de lenguajes de programación, incluyendo HTML o Python, como también plataformas.

Aspectos clave:

- Compatible con una amplia gama de lenguajes de programación.
- Ofrece una gran cantidad de extensiones para agregar funcionalidades.
- La funcionalidad IntelliSense te permite obtener sugerencias de autocompletado en base a los tipos de variables, funciones, etc.
- Compatibilidad con Git.

**-Sublime Text** es un editor de código abierto gratuito desarrollado por Jon Skinner. Fue lanzado en 2008 y, desde entonces, ha ganado gran popularidad entre los desarrolladores por ser un editor potente y versátil, además de ser una buena opción para aquellos que necesitan una herramienta de alto rendimiento. Se puede descargar gratuitamente u obtener la licencia de pago para un uso más profesional.

Aspectos clave:

- Multitud de atajos de teclado que agilizan el trabajo.
- Sistema de pantallas múltiples que permite trabajar con varios documentos a la vez.
- Cuenta con numerosos plugins.
- Su resultado de sintaxis es uno de los mejores del mercado.
- Consume pocos recursos.

## Extensiones recomendadas de Visual Studio Code

- **Live Server**, crea un servidor web local para que puedas escribir código y cada que guardes los cambios verás los resultados en el navegador en automático.

- **Emmet**, es la extensión más útil que existe para escribir HTML, ya que estos lenguajes se caracterizan porque hay que escribir mucho código y emmet nos da atajos sencillos de recordar para escribir HTML super rápido.

- **Live Share**, convierte Visual Studio Code en un Google Docs porque puedes tener a todo tu equipo trabajando en el mismo proyecto. Verás el cursor de cada uno para saber que están trabajando.

- **CodeSnap**, te ayuda a compartir tu código como imagen que se vea atractiva. Por ejemplo, si tienes que hacer una presentación con diapositivas que incluya extractos de código.

- **Auto Rename Tag**, simplifica la edición de HTML. Cuando renombras una etiqueta HTML (por ejemplo, cambias un div a section), esta extensión renombra automáticamente la etiqueta de cierre correspondiente. Esto evita errores comunes de etiquetas no coincidentes y acelera la refactorización de tu marcado HTML. Es una pequeña característica que ofrece una gran mejora en la productividad para el desarrollo web. [2] [3]


## Problemas comunes de Visual Studio Code

**-Problema de conectividad durante la descarga**
Estos errores suelen producirse cuando el instalador de Visual Studio experimenta problemas que afectan a la conexión a Internet durante la descarga de los componentes necesarios. Cuando reciba uno de estos mensajes de error, pruebe a reinstalar Visual Studio cuando mejore la conexión a Internet. Si sigue experimentando este error, pruebe los métodos siguientes:

- Instale Visual Studio desde otro origen.

- Instale Visual Studio mediante el modificador layout o un archivo ISO. Para más información sobre cómo hacer esto, consulte Instalar Visual Studio 2015.

**-Acceso denegado**
Este error se produce cuando Visual Studio no puede acceder a uno o más de los archivos de instalación necesarios. Este error puede producirse por cualquiera de los motivos siguientes:

- Un proceso externo, como una aplicación antivirus o antimalware, ha bloqueado un archivo de instalación de Visual Studio al mismo tiempo que Visual Studio intentaba instalarlo. Para evitar este problema, coordínese con el administrador del sistema u otro profesional de TI para asegurarse de que estos procesos no bloqueen los archivos de Visual Studio.

- El usuario que intenta instalar Visual Studio no dispone de credenciales de administrador en el equipo. Para instalar Visual Studio correctamente, debe haber iniciado sesión como administrador.

- Los permisos en algunos subárboles del Registro pueden impedir la instalación correcta de Visual Studio. Para solucionar este problema, consulte Resolver errores de configuración utilizando la herramienta SubInACL.

**-Caché o ISO de instalación dañado**
- Este error suele producirse cuando un archivo relacionado con la instalación se daña. Puede experimentar este error al instalar Visual Studio mediante una imagen ISO o un DVD grabado a partir de una imagen ISO. También podría experimentar este error durante una reparación de Visual Studio. [5]
