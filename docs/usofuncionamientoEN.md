HTML is responsible for structuring content, making it accessible on different devices, and serving as a foundation for working with other languages such as CSS or JavaScript.

An HTML document allows us to:

- Organize text using headings, paragraphs, and lists.
- Insert images, videos, and audio files.
- Create hyperlinks to connect pages.
- Define forms to capture user data.
- Establish the semantic structure that search engines analyze.
## How HTML Works
<img src="/Users/adrianlopezruiz/Desktop/ASIR/2ºASIR/Servicios de red e internet/1 TRIMESTRE/RA3html/img/funcionamientohtml.png">

HTML (*HyperText Markup Language*) is the language used to create and structure the content of a web page. It works by using tags that tell the browser which elements to display and how they are organized within the page.

When a web page is created with HTML, the code is written in a file with the `.html` extension, using a text editor such as Visual Studio Code. Inside that file, different tags are added that make it possible to include headings, paragraphs, images, links, lists, and other elements.

Once the document has been created, the web browser, such as Google Chrome, Firefox, or Safari, reads and interprets the HTML code. The browser recognizes the tags and uses them to build the structure of the page, displaying the content in a way that the user can understand and use. [1]

## How Is an HTML Page Loaded?

The process begins when a user enters a web address in the browser or clicks on a link. The browser sends a request to the server where the web page is hosted. The server receives that request and returns the necessary files, including the HTML document.

The browser then interprets that document and displays its content on the screen. This process allows the user to view the web page and interact with it.

## How Does the Browser Interpret Tags?

HTML uses tags that normally have an opening and a closing tag. For example, the `<p>` tag is used to create a paragraph and `</p>` indicates where it ends. The content is placed between both tags.

In this way, the browser can identify the function of each part of the document and display it correctly.

In addition, HTML makes it possible to organize the page through a structure made up of different parts:

- **`<html>`:** contains the entire HTML document.
- **`<head>`:** contains information about the document, such as its title or character encoding.
- **`<body>`:** contains the elements that appear visibly on the web page.[2]

## Relationship Between HTML and Other Languages

HTML can be combined with other languages to improve the functionality and appearance of a web page:

- **CSS:** used to control its appearance, such as colors, sizes, fonts, and the layout of elements.
- **JavaScript:** makes it possible to add interactivity and dynamic functions to the web page. [3]
