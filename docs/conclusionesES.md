# Conclusiones y mejoras futuras ES

## Conclusiones

Con esta guía hemos aprendido qué es HTML, para qué sirve y cómo se utiliza para crear páginas web. También hemos conocido algunas de sus etiquetas principales y cómo se organiza un documento HTML.

Durante la realización del trabajo hemos podido comprender mejor cómo funciona HTML y cómo se utiliza para añadir títulos, párrafos, imágenes y enlaces a una página web. Al principio algunos conceptos nos han resultado complicados ya que es una parte de HTML bastante más profundo que no hemos llegado a tocar, pero al ir probando las etiquetas y viendo los resultados es más fácil entender su funcionamiento.

En general, este trabajo nos ha servido para tener una primera toma de contacto con el desarrollo web y conocer las bases necesarias para empezar a crear nuestras propias páginas utilizando el lenguaje de HTML.

## Mejoras futuras

Aunque en esta guía hemos explicado los aspectos más básicos de HTML, creemos que se podrían añadir más contenidos para hacerla más completa.

Algunas mejoras que podríamos realizar en el futuro son:

- **Añadir más etiquetas HTML:** explicar otras etiquetas y su utilidad.
- **Incluir formularios y tablas:** mostrar cómo crear estos elementos en una página web.
- **Aprender CSS:** explicar cómo cambiar los colores, las fuentes y el diseño de las páginas.
- **Introducir JavaScript:** enseñar cómo añadir interactividad a una página web.
- **Crear una página web completa:** poner en práctica todos los conocimientos aprendidos durante la guía.
