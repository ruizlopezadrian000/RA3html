# Guía de uso de HTML
Bienvenido a esta guía de uso de HTML.

En este proyecto vamos a aprender qué es HTML,
para qué sirve y cómo se utiliza para crear páginas web.

HTML es un lenguaje de marcado que permite organizar
el contenido de una página web mediante etiquetas.

## Objetivos
- Conocer qué es HTML.
- Aprender a utilizar sus etiquetas principales.
- Crear una página web básica.
- Conocer la estructura de un documento HTML.
