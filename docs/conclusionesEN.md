## Conclusions

With this guide we have learned what HTML is, what it is used for, and how it is used to create web pages. We have also become familiar with some of its main tags and how an HTML document is organized.

While working on this project, we were able to better understand how HTML works and how it is used to add titles, paragraphs, images, and links to a web page. At first, some concepts were complicated for us, since it is a much deeper part of HTML that we have not managed to explore, but by trying out the tags and seeing the results, it becomes easier to understand how they work.

Overall, this project has given us a first introduction to web development and taught us the basics needed to start creating our own pages using the HTML language.
