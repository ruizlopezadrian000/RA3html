Welcome to this HTML usage guide.

In this project we are going to learn what HTML is,
what it is used for, and how it is used to create web pages.

HTML is a markup language that allows you to organize
the content of a web page by means of tags.

## Objectives
- Learn what HTML is.
- Learn how to use its main tags.
- Create a basic web page.
- Learn the structure of an HTML document.
