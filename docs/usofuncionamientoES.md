# Uso y funcionamiento del HTML
## Uso del HTML
<img src="/Users/adrianlopezruiz/Desktop/ASIR/2ºASIR/Servicios de red e internet/1 TRIMESTRE/ra3ser/RA3html/img/usohtml.jpg">
HTML se encarga de estructurar el contenido, hacerlo accesible en distintos dispositivos y servir de base para trabajar con otros lenguajes como CSS o JavaScript.

Un documento HTML nos permite:

- Organizar textos mediante títulos, párrafos y listas.
- Insertar imágenes, vídeos y archivos de audio.
- Crear hipervínculos para conectar páginas.
- Definir formularios para capturar datos del usuario.
- Establecer la estructura semántica que analizan los motores de búsquedas.

## Funcionamiento del HTML
<img src="/Users/adrianlopezruiz/Desktop/ASIR/2ºASIR/Servicios de red e internet/1 TRIMESTRE/ra3ser/RA3html/img/funcionamientohtml.png">

HTML (*HyperText Markup Language*) es el lenguaje que permite crear y estructurar el contenido de una página web. Su funcionamiento se basa en utilizar etiquetas que indican al navegador qué elementos debe mostrar y cómo están organizados dentro de la página.

Cuando se crea una página web con HTML, se escribe el código en un archivo con extensión `.html`, utilizando un editor de texto como Visual Studio Code. Dentro de ese archivo se introducen diferentes etiquetas que permiten añadir títulos, párrafos, imágenes, enlaces, listas y otros elementos.

Una vez creado el documento, el navegador web, como Google Chrome, Firefox o Safari, se encarga de leer e interpretar el código HTML. El navegador reconoce las etiquetas y las utiliza para construir la estructura de la página, mostrando el contenido de una forma que el usuario pueda entender y utilizar.

## ¿Cómo se carga una página HTML?

El funcionamiento comienza cuando un usuario introduce una dirección web en el navegador o pulsa sobre un enlace. El navegador realiza una petición al servidor donde está alojada la página web. El servidor recibe esa petición y devuelve los archivos necesarios, entre ellos el documento HTML.

Después, el navegador interpreta ese documento y muestra su contenido en pantalla. Este proceso permite que el usuario pueda visualizar la página web e interactuar con ella.

## ¿Cómo interpreta el navegador las etiquetas?

HTML utiliza etiquetas que normalmente tienen una apertura y un cierre. Por ejemplo, la etiqueta `<p>` sirve para crear un párrafo y `</p>` indica dónde termina. El contenido se coloca entre ambas etiquetas.

De esta manera, el navegador puede identificar qué función tiene cada parte del documento y mostrarla correctamente.

Además, HTML permite organizar la página mediante una estructura formada por diferentes partes:

- **`<html>`:** contiene todo el documento HTML.
- **`<head>`:** contiene información sobre el documento, como su título o la codificación de caracteres.
- **`<body>`:** contiene los elementos que aparecen visibles en la página web.

## Relación de HTML con otros lenguajes

HTML se puede combinar con otros lenguajes para mejorar el funcionamiento y la apariencia de una página web:

- **CSS:** se utiliza para controlar su apariencia, como los colores, tamaños, fuentes y distribución de los elementos.
- **JavaScript:** permite añadir interactividad y funciones dinámicas a la página web.
