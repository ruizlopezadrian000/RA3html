# Forma al texto documento HTML
Cuando escribimos el contenido que queremos mostrar en una página web, el texto se adapta automáticamente al tamaño de la pantalla, sin necesidad de utilizar la tecla Intro para cambiar de línea. Si queremos organizar el contenido en diferentes párrafos, debemos utilizar la etiqueta `<p>`, que normalmente se cierra con `</p>`.

También podemos incluir títulos y encabezados mediante las etiquetas `<h1>` hasta `<h6>`. Cada una representa un nivel de encabezado diferente, siendo `<h1>` el de mayor tamaño y `<h6>` el más pequeño.

Otra etiqueta que podemos utilizar es `<center>`, que permite centrar el contenido que se encuentra dentro de ella, como textos o imágenes. Aunque no todos los navegadores la reconocen, la mayoría sí la admite.

Por último, HTML dispone de la etiqueta `<hr>`, que sirve para insertar una línea horizontal y separar visualmente distintas partes del contenido. Esta etiqueta no necesita una etiqueta de cierre y, por defecto, ocupa el ancho disponible del elemento en el que se encuentra.
